# 🎵 Flutter Local Music Player

A minimalist, offline-first music player built using **Flutter**. Designed with a modern **Material 3 Expressive UI** and smooth **glassmorphism (blur)** aesthetic, this app allows you to enjoy your local music library effortlessly.

---

### ✨ Features
* **Offline Audio Playback:** Supports common local audio formats including **MP3, M4A, and FLAC**.
* **Material 3 Expressive:** Modern and clean user interface tailored with dynamic color schemes and smooth components.
* **Glassmorphism UI:** Features aesthetic translucent blur effects (`BackdropFilter`) for album art containers.
* **Lightweight & Fast:** Built natively with Flutter for optimal performance on Android.

---

### 🛠️ Tech Stack & Packages
* **Framework:** [Flutter](https://flutter.dev/)
* **Audio Engine:** `audioplayers`
* **File Picker:** `file_picker`
